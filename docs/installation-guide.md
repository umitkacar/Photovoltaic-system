## 🛠️ Pre-Installation

### Site Assessment Checklist

**Roof Assessment**:
- [ ] Roof age (<15 years preferred)
- [ ] Structural capacity (5+ lb/sq ft)
- [ ] Roof condition (no active leaks)
- [ ] Shading analysis (Solar Pathfinder)
- [ ] Electrical panel capacity
- [ ] Utility meter location

**Safety Assessment**:
- [ ] Fall hazards identified
- [ ] Electrical hazards noted
- [ ] Access routes planned
- [ ] Emergency procedures established

## ⚠️ Safety Requirements (OSHA)

### Applicable Standards

| Standard | Title | Key Requirements |
|----------|-------|------------------|
| **29 CFR 1910.269** | Electric Power Generation | Electrical safety, arc flash protection |
| **29 CFR 1926** | Construction | General construction safety |
| **29 CFR 1926.501** | Fall Protection | Fall arrest systems ≥4 feet |
| **29 CFR 1910.132** | PPE | Personal protective equipment |

---

### Personal Protective Equipment (PPE)

**Required for All Workers**:
- ✅ ANSI Z87.1 safety glasses (impact-resistant)
- ✅ Hard hat (ANSI Z89.1)
- ✅ Work gloves (cut-resistant)
- ✅ Steel-toe boots (ASTM F2413)
- ✅ High-visibility vest (ANSI 107)

**Roof Work** (>4 feet):
- ✅ Full-body harness (ANSI Z359)
- ✅ Shock-absorbing lanyard
- ✅ Roof anchor points (certified)
- ✅ Guardrails (where possible)

**Electrical Work**:
- ✅ Arc-rated clothing (NFPA 70E)
- ✅ Insulated gloves (rated for voltage)
- ✅ Non-conductive footwear

---

### Safety Protocols

**Daily Safety Meeting** (15 min before work):
1. Review day's tasks
2. Identify hazards
3. Weather conditions
4. Emergency procedures
5. Verify PPE compliance

**Lockout/Tagout (LOTO)**:
- Main breaker OFF during installation
- Lock and tag breaker
- Verify de-energization with multimeter
- Only authorized person removes lock

## 📋 Installation Procedures

### Phase 1: Site Preparation (2-4 hours)

**Step 1: Staging** (30 min)
- Unload panels (store flat, shaded)
- Inventory all components
- Set up tools and safety equipment
- Establish work zones

**Step 2: Roof Layout** (1-2 hours)
- Mark array boundaries
- Locate rafters (stud finder)
- Mark attachment points
- Verify clearances (fire code setbacks)

**Step 3: Safety Setup** (30 min)
- Install roof anchors
- Deploy guardrails (if using)
- Set up ladder access
- Post warning signs

**Man-Hours**: 2 workers × 2 hours = **4 man-hours**

---

### Phase 2: Racking Installation (6-10 hours)

**Critical**: Racking is **70% of installation time**

**Step 1: Install Flashings** (2-4 hours)
```
Per flashing:
1. Mark location (centered on rafter)
2. Lift shingles with pry bar
3. Apply sealant around perimeter
4. Insert flashing under shingles
5. Secure to rafter (lag bolts, torque 25 ft-lb)
6. Re-seal shingles
Time: 10-15 min per flashing
```

**Example**: 40 flashings × 12 min = **8 hours** (for 2 workers = 4 hours elapsed)

**Step 2: Install Rails** (2-3 hours)
- Attach L-feet to flashings
- Level and secure rails
- Verify row spacing (uniform)
- Apply thread locker to all bolts

**Step 3: Install Cross-Members** (1-2 hours)
- Attach module clamps
- Space per panel width
- Verify square and level

**Man-Hours**: 2 workers × 8 hours = **16 man-hours**

---

### Phase 3: Panel Installation (4-6 hours)

**Step 1: Panel Lifting** (use hoist or panel lifters)
- Never exceed safe lifting weight (50 lb/person)
- Use tag lines for control
- Stage panels on roof (secure to prevent sliding)

**Step 2: Panel Mounting**
```
Per panel:
1. Place panel on rails
2. Attach mid-clamps (do not overtighten!)
3. Torque to spec (typically 12-15 ft-lb)
4. Verify gap between panels (1/4" to 1/2")
Time: 5-8 min per panel
```

**Example**: 20 panels × 6 min = **120 min = 2 hours**

**Step 3: Grounding**
- Attach grounding lugs to each rail
- Run grounding conductor (#6 AWG bare copper)
- Bond all metal components

**Man-Hours**: 2 workers × 5 hours = **10 man-hours**

---

### Phase 4: Electrical (DC Wiring) (4-6 hours)

**Step 1: String Wiring**
- Connect panels in series (MC4 connectors)
- Verify polarity (+/-)
- Secure cables with cable clips
- Route to combiner box/inverter

**Step 2: Conduit & Home Runs**
- Install conduit (EMT or PVC)
- Pull PV wire (10 AWG typical)
- Label all conductors
- Torque terminals (per manufacturer spec)

**Step 3: DC Disconnect**
- Install fused disconnect (near inverter)
- Wire input (from panels) and output (to inverter)
- Verify fuse rating (1.56 × Isc)

**Man-Hours**: 2 workers × 5 hours = **10 man-hours**

---

### Phase 5: Inverter & AC (3-4 hours)

**Step 1: Inverter Mounting**
- Install wall bracket (concrete anchors or studs)
- Mount inverter (typically indoors)
- Maintain clearances (per manual)

**Step 2: DC Connection**
- Connect PV input terminals
- Torque to spec (typically 40 in-lb)
- Verify polarity with multimeter

**Step 3: AC Connection**
- Run AC circuit to main panel
- Install AC disconnect (if required)
- Install breaker in main panel
- Label breaker ("SOLAR PV")

**Man-Hours**: 1 electrician × 4 hours = **4 man-hours**

---

### Phase 6: Testing & Commissioning (2-3 hours)

**Pre-Energization Tests**:
- [ ] VOC measurement (each string)
- [ ] ISC measurement (clamp meter)
- [ ] Insulation resistance (megger test >1 MΩ)
- [ ] Polarity verification
- [ ] Grounding continuity (<1Ω)

**Energization**:
1. Close DC disconnect
2. Verify inverter display (initializing)
3. Close AC breaker
4. Monitor for faults (first 10 min)

**Performance Verification**:
- Power output (compare to expected)
- Voltage/current readings
- AC frequency (59.9-60.1 Hz)
- No ground faults

**Man-Hours**: 1 tech × 2 hours = **2 man-hours**

## ✅ Quality Control & Testing

### Inspection Checklist

**Mechanical**:
- [ ] All bolts torqued to spec
- [ ] No gaps between panels >1/2"
- [ ] Flashings sealed (no potential leaks)
- [ ] Rails level and square
- [ ] Grounding lugs tight

**Electrical**:
- [ ] All MC4 connections clicked (secure)
- [ ] No exposed conductors
- [ ] Proper conductor sizing (per NEC)
- [ ] Labels affixed (per NEC 690.56)
- [ ] Voltage/current within expected range

**Safety**:
- [ ] Rapid shutdown compliant (NEC 690.12)
- [ ] Fire setbacks maintained
- [ ] AC/DC disconnects labeled
- [ ] Warning labels visible

---

### Performance Testing

**I-V Curve Tracing**:
- Use PV analyzer (e.g., Solmetric PVA-1500)
- Capture I-V curve for each string
- Compare to expected (datasheet)
- Identify underperformers (shading, damage)

**Thermal Imaging**:
- Scan array with IR camera
- Identify hotspots (>10°C above ambient)
- Hotspots indicate: cracked cells, bad connections, diode failure

## 🎯 Key Takeaways

### ✅ Safety First
1. **OSHA compliance** mandatory (1910.269, 1926)
2. **Fall protection** required >4 feet
3. **Daily safety meetings** prevent accidents
4. **PPE** always: hard hat, safety glasses, harness

### ✅ Time Management
1. **Racking = 70%** of installation time
2. **2-person crew** optimal for residential
3. **6-person crew** optimal for commercial
4. **Weather delays** add 10-20% contingency

### ✅ Quality
1. **Torque all fasteners** (prevents loosening)
2. **Test before energizing** (avoid expensive mistakes)
3. **Document everything** (photos, test results)
4. **Final inspection** by AHJ required
